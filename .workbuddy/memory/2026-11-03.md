# 2026-11-03

## 网络监控中心（绿色便携 exe）开发完成
- 需求：Win11 免安装单文件 exe，实时监控本机 IP/端口、网卡状态与跃点数（用户写"约点数"，确认为跃点数 Metric），可配置跃点数，界面简洁。
- 技术栈：Python 3.12 + tkinter(clam 自定义浅色主题) + psutil；底层用 ctypes 调 iphlpapi GetAdaptersAddresses 读取 IP/掩码/网关/跃点（与 netsh 输出核对一致）。
- 修改跃点：netsh interface ipv4/ipv6 set interface <名> metric=<n>|automatic（位置参数，list 传参即可，中文含空格名 OK；输出 UTF-8，需 utf-8 优先解码）。已实测 35→36→35→automatic 往返成功。
- 打包：PyInstaller --onefile --windowed，--add-data icon.ico 用绝对路径（相对路径相对 specpath 会找不到）。产物 dist/网络监控中心.exe 约 10.2MB。
- 图标：tools/make_icon.py 纯 Python 光栅化生成多尺寸 PNG-in-ICO。
- 辅助：tools/shot.py 用 GDI BitBlt+手写 PNG 编码截窗口（环境禁 Add-Type/PIL 时的替代）。
- 坑：psutil UDP 状态为 NONE→显示"—"；后台线程向 tkinter 传数据用 queue+after 轮询；--scope user 安装官方 Python 3.12 到 AppData（便携 Git Bash 的 python 无 tkinter）。
- 环境注意：winget 可用；本机为管理员；屏幕 125% 缩放（物理 1920x1200）。

## 11:13 新增：内外网一键优先切换
- 需求：同时连内网(以太网 8, 10.254.217.87)和外网(WLAN 192.168.61.102)，需要一键切换优先出口。
- 方案：调整两张网卡 IPv4 跃点数（优先=10，另一=100）实现默认路由切换；直连网段/静态路由不受影响。
- 实现：`_switch_adapters()` 按 config.switch（lan_ip/lan_name/wan_name/low/high，默认已按用户环境预置）识别网卡，找不到按 10.x 段与无线特征回退；`_mode_of()` 比较 metric_v4 判定当前模式；`_toggle_mode()` 后台 netsh 双写 + `_switch_done` 回调；Tab1 顶部新增切换栏（按钮+当前模式+两网卡信息）。
- 顺带修复：_update_status 会在 2 秒刷新时覆盖状态栏 toast，改为 _toast_until 时间戳保护。
- 真实验证：初始 wan(25/20) → 内网优先(10/100) → 外网优先(100/10) → 恢复自动(25/35)，UI 文本与模式判定同步正确。
